separatrix

Quantum-inspired optimisation you can check.

A simulated-bifurcation solver in pure Rust — the Toshiba-lineage algorithm (Goto et al., Science Advances 2019 & 2021) — benchmarked the only honest way: next to simulated annealing, parallel tempering and exact ground truth. A Solana program re-derives every committed answer on-chain. The same “exactly k of n” constraint is then taken to quantum hardware primitives and measured like a referee would.

Three pillars, one repository

01 · solver

Simulated bifurcation, with its baselines in the box

bSB and dSB next to SA, parallel tempering and Gray-code exact enumeration. Deterministic per seed, compiles to wasm32, and scores every solution on a quantized i128 objective that anyone can replay.

honesty contract

The rules this project holds itself to

  • Quantum-inspired is a description, not a claim. Simulated bifurcation is a classical Hamiltonian ODE; nothing in the solver touches a qubit.
  • Ground truth or nothing. The enumerator refuses instances it cannot finish, and where exact enumeration wins the docs say so.
  • The chain checks, it does not trust. The objective the program computed equalled the solver’s integer exactly, or the reveal would have failed.
  • Property tests enforce that no heuristic ever reports an energy below the exact ground state.
